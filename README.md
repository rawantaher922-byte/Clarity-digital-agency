# Clarity-digital-agency
##  About The Project

Clarity is a modern, responsive digital agency website designed to showcase professional digital services and help businesses transform their online presence.

The website presents the agency's services, highlights its strengths, answers frequently asked questions, and allows potential clients to request a free consultation.

## Features

- Modern and responsive user interface.
- Attractive hero section with company statistics.
- Digital services showcase.
- Web Development services.
- Mobile App Development services.
- Company benefits and reasons to choose Clarity.
- Frequently Asked Questions (FAQ) section.
- Contact form for free consultation requests.
- Responsive navigation and layout.
- Interactive UI elements and icons.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Font Awesome

## Getting Started
1. Clone the repository:

   ```bash
   git clone https://github.com/rawantaher922-byte/Clarity-digital-agency.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Clarity-digital-agency
   ```

3. Open the project in Visual Studio Code.

4. Run `index.html` using Live Server.

5. Explore the website!

## Responsive Design
